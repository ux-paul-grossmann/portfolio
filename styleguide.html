Type scale

Proposed ramp — tokens in style.css

Five steps, roughly 1.25 apart (12, 16, 20, 25, 32, 40), one weight rule per role: Inter for text and headings, Merriweather only for the intro statement.

Display — 40 --type-display · 40 / 1.2
Statement — 32 · Merriweather --type-statement · 32 / 1.3
Heading — 25 --type-heading · 25 / 1.3
Subheading — 20 --type-subheading · 20 / 1.3
Body — 16. Hey, ich bin Paul Großmann. --type-body · 16 / 1.55
Caption — 12 --type-caption · 12 / 1.55

Today — Bootstrap heading sizes

First row is the intro statement, styled by its own rule. The rest are Bootstrap h1 to h5. Values read as: font-size / weight / line-height. Taken from Bootstrap's h1 to h5: 2.5 / 1.75 / 1.25 / 1 / 0.75 rem, so the steps are 1.43, 1.4, 1.25 and 1.33 — a heading scale, not a modular one.
