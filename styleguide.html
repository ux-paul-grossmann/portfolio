Type scale

First row is the intro statement, styled by its own rule. The rest are Bootstrap h1 to h5. Values read as: font-size / weight / line-height. Taken from Bootstrap's h1 to h5: 2.5 / 1.75 / 1.25 / 1 / 0.75 rem, so the steps are 1.43, 1.4, 1.25 and 1.33 — a heading scale, not a modular one.
